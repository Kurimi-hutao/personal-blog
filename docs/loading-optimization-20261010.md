# 手机与桌面加载优化（2026-10-10）

## 修改

- 首页春日场景、小屋日夜背景共 29 张 PNG 转为 WebP，保留尺寸和透明通道，原图保留供维护。运行时引用更新为 WebP。
- 这些图片合计从 38,788,609 字节降至 4,643,470 字节，减少 88.0%。首页手机山景为 140,332 字节，小屋手机夜景为 268,744 字节。
- Service Worker 安装只预缓存独立的离线提示页。页面、图片、字体与模块按访问需要缓存；字体和图片优先复用缓存，脚本和样式后台更新，页面导航优先访问网络。
- 清理旧版博客缓存时保留其他名称的缓存。视频、Range 请求及跨域服务请求不进入博客缓存。
- 主站共享印章加载层取消会话跳过及固定时长退出，等待当前页面的字体请求完成后淡出。先触发公共字体加载，再等待字体集合就绪；字体请求失败后允许使用系统字体。
- 印章与墨晕循环播放，加载提示使用系统字体。减少动态效果模式保留静态印章与同样的字体等待逻辑。
- 更新主站相关脚本、样式引用和缓存版本。

## 验证

运行 `node scripts/check-loading.cjs`，使用本地 Chrome 和临时本地服务器，拦截外部网络请求，不写入线上数据库。

- 在修复前复现：拦截字体请求，已有会话下加载层不显示。
- 手机 390px / 桌面 1440px，分别检查正常动画与减少动态效果模式：字体请求延迟期间加载层保持；正常模式印章持续循环；字体放行后加载层移除，字体集合已完成加载，页面无横向溢出与未捕获脚本异常。
- 字体请求失败时，文章列表页面解除加载层与滚动锁。
- 小屋日夜背景在双端采用 WebP，无资源 404 与横向溢出。
- 实际启用 Service Worker：首页不预下载小屋、后台与视频页；旧博客缓存清理，其他缓存保留；重复访问复用字体缓存；已访问首页可离线打开，未缓存地址显示离线提示。
