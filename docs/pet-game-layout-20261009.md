# 小屋小游戏布局与按钮间距修复

## 修复的问题

浏览器复现了开关状态导致的移位：1000px 宽度时，“动态”“声音”图标在关闭后横移约 86px；768px 时横移约 48px。原因是 `.mini-toggle.is-on` 与平板断点的 `.mini-toggle` 使用不同的对齐规则，样式优先级又不同。场景标签长度变化也会让居中的图标与文字整组移动。

统一了开启和关闭状态的 Grid 布局：按钮宽高、图标栏、文字栏和内边距完全相同。图案与文字内容改变时，按钮、图标及文字栏的几何位置保持不变。切换时只改变图案、文本、状态属性及底色。

768px 宽度下还复现了按钮子元素超出格子的问题。原先六列按钮同时使用不换行的说明文字；现在把设置移出底栏，互动按钮使用独立格子、12–24px 横向间距，说明文字允许换行。900px 及以下改为三列两行，为每个按钮保留完整空间。

## 布局

- 顶部为常驻状态栏：头像、角色名、等级、桃花币，以及固定的动态、声音、场景设置。窄屏设置另成一行。
- 中间为场景与角色；养成手记可以展开，保留经验、属性和每日小礼。
- 底部为独立互动区：标题与归位按钮、串门入口、六个互动按钮。设置与互动区的位置互不影响。
- 下方“来访伙伴 / 每日小事”使用分页切换，避免同时铺开所有卡片。分页支持点击、左右方向键、Home、End，并提供 ARIA tab/tabpanel 关系。
- 保留现有模型、素材、角色切换、每日奖励、场景记忆与原存档键。

## 验证

`node scripts/check-pet-game-layout.cjs` 对 320、390、768、1000、1100、1440、1920px 逐一检查：

- 动态和声音的两种状态、场景的五种状态，按钮、图标和文字栏位置与宽高变化不超过 0.5px。
- 每个互动按钮的图标、木牌、说明文字均位于自己的横向区域内。
- 无页面横向溢出、无脚本错误。
- 分页显示与键盘切换正常。

七种宽度全部通过。截图与结果保存在 `screenshots/pet-game-layout/`。
