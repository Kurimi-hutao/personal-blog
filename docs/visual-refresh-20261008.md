# 素材接入与本地预览 · 2026-10-08

13 张用户原图原样保存在 `sources/visual-refresh/`。网页衍生文件在
`assets/visual-refresh/`，包含透明 WebP、横版/竖版夜景、PNG 图标及多尺寸 ICO。
原图约 21.3 MB，全部网页衍生文件合计约 1.45 MB；按实际页面使用。

## 接入位置

- 虎桃印章：首次进入首页的墨点落印开场；每个会话只出现一次，减少动态效果时跳过。
  开场显示约 560–780 ms，退出 220 ms，首页不再追加第二段开场等待。
  留言、评论和首次签到成功后显示小印章。
- 卷轴插画：文章、视频及全站搜索的无结果状态，首页无内容状态。
- 信笺插画：首页无留言、文章无评论状态。
- 小桥插画：文章、视频、评论、留言等读取失败状态，提供重试入口。
- 毛笔图标：留言表单；卷轴：文章标题和寻卷；灯笼：视频标题；书签：收藏；花印：签到。
- 夜景：文章、视频、作品页在暗色主题下使用对应横版图；700 px 以下改用竖版。
- iOS 主屏幕图标：180 px apple-touch-icon；安装清单：192/512 px；favicon：16/32/48 px ICO 和 PNG。
- 原有日间场景及各独立子站保留。

`ink-assets.js` 提供公共插画状态、淡墨加载占位、成功印章和小图标。
`ink-assets.css` 提供相应布局及夜景适配。根目录 HTML 已接入公共组件与新图标，
service worker 缓存版本已更新。

## 本地运行

在项目根目录运行 `python -m http.server 8000 --bind 127.0.0.1`，访问
`http://127.0.0.1:8000/`。在文章、视频、作品页面点击「夜」查看新夜景。

## 验证

运行 `node scripts/check-visual-refresh.cjs`。截图及结果位于
`screenshots/visual-refresh/`。

浏览器检查覆盖 1440/390/320 px、日夜页头、对应夜景选择、横向溢出、
搜索无结果与清除筛选、空评论和留言、图标接入、读取失败后重试、
加载占位、减少动态效果、首次开场和再次访问跳过开场。
检查使用仅注入测试浏览器的隔离内容，不写入线上文章或留言。
iOS 图标的实际添加到主屏幕效果仍需在 iPhone 上确认。
