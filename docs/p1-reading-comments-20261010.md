# P1 阅读与评论升级（2026-10-10）

## 阅读

- 按文章保存正文阅读比例，重新打开时提供“继续阅读 / 从头阅读”。进度以正文计算，不把评论长度计入；读完清除续读记录。不自动跳转，明确的章节链接优先。
- 中小屏默认折叠正文前目录，阅读正文时显示目录浮动入口，打开为可滚动的对话框，支持章节跳转、Escape 关闭和当前章节标识。桌面保留侧栏目录。
- 全站搜索面板增加“我的收藏”和“查看全部收藏”，可按标题、分类、标签筛选、逐项移除；收藏保存在当前浏览器。原有收藏数据兼容，新增收藏保存分类和标签。

## 评论

- 文字、纯图片或图文发送，支持图片选择、粘贴、拖入、发送前缩略图与移除，评论图片可点开大图。
- 可沿用昵称，留空生成访客昵称；Enter 换行，Ctrl / Command + Enter 发送，输入法组合输入期间不触发发送。
- 保留最多 3 个附件、单个 5 MB，支持 PNG / JPEG / GIF / WebP / TXT / PDF。
- 主楼按创建时间编号，置顶只改变展示顺序。楼内回复保存具体被回复者，显示“回复 @昵称”；超过 3 条楼内回复可展开。刚发送的回复自动展开。
- 文字、昵称、回复对象保存在 localStorage；图片与文件草稿保存在 IndexedDB，按文章隔离。图片仅在附件变化时持久化，避免每次输入文字重写大文件。
- 防重复提交，发送失败保留草稿，同页重试复用已成功上传的附件。图片草稿存储不可用时明确提示。
- 删除旧服务的静默降级逻辑，防止数据库缺字段时把楼内回复错误发送为主楼。

## 无迁移启用

新版沿用现有 `comments` 表、`parent_id` 与 `attachments` JSON 字段，不改表、不复制或删除历史评论。

回复对象和纯图片标志写入附件 JSON 内的 `__hutao_comment` 版本化元数据；有附件时附着在第一个附件上，无附件的文字回复使用单个上下文条目。服务层统一解码并过滤上下文条目，前台和后台都接收正常的正文与文件列表。纯图片评论使用兼容旧非空约束的文字占位，展示时依据元数据还原为空正文；附件总数仍不超过 3。

旧评论直接读取。已有数据库的主楼关系验证、访问控制与频率限制继续生效。只需部署前端即可启用，不需要数据库管理凭据。
