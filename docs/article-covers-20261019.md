# 文章封面跟进

桌面首页原先将 16:9 封面放在高度由文字决定的侧栏中，封面下方留下明显空白；较窄的次要卡片也挤压了封面。901px 以上改为上图下文，所有卡片使用通栏 16:9 画框，图片 `object-fit: contain`，完整保留原图。

未设置图片的文章从四张现有水墨插画中分配默认封面。使用文章标识做散列分配，效果分散，同一篇文章在首页、文章列表、筛选和刷新后保持一致。显式封面优先；图片加载失败时尝试默认封面一次，避免无限重试。视频封面不受影响，不写入或修改文章数据。

验证：`node scripts/check-article-covers.cjs` 在 390、900、1080、1440、1920px 深浅色下检查封面完整显示、默认封面正常加载与分散选择、跨页面及刷新稳定、已有封面保留、无横向溢出。使用 main 实际页面与脚本的隔离副本再次执行。旧版本会在未设置封面文章没有插画的断言上失败。
