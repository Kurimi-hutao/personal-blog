# 国风刊物排版与 iPhone 检查 · 2026-10-15

用户选择“国风刊物：克制排版、山水留白、少量朱红”。上一版过多方框、印边、重复场景和细小文字使手机界面过于机械，本次减少装饰并调整排版。

- 手机主操作采用单一墨色按钮；取消重复印框与双层描边，保留线稿工具图标、触摸反馈和 44px 操作区域。
- 目录通过字号、细线与留白分层，辅助工具改为两列横向图标文字，短横屏改为一行工具。
- 文章、视频、作品列表取消重复的大幅书案页头；标题与简介更紧凑，使文章内容提前进入首屏。
- 修正 .article-filters 选择器及 :has(#sortArticles) 的优先级，搜索框保持 16px，分类与排序各占半行，清除入口位于输入框右侧。
- 正文 16px/1.95，摘要 15px，移动封面标题 21px；减少小字和红色元信息。
- 设置 viewport-fit=cover 与 safe-area CSS 变量，避让顶部、底部及横屏边缘；搜索弹窗按可视视口与安全区限制高度。
- 续读进度和滚动位置使用实际阅读栏高度，修复安全区增高后的遮挡；目录跳转保留相同避让。
- 素材需求及 GPT 提示词见 mobile-publication-assets.md。现有图仍作为过渡，等待手机专用构图素材。
