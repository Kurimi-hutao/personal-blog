# 双端文章排版与动效

首页文章区、文章列表与阅读页标题使用统一的字体层级。桌面首页首篇采用横向主推布局，其余为双列图文；文章列表采用封面与摘要并排。手机统一为 2:1 封面、分类与日期、两行标题及摘要，使用细分隔线替代重卡片面板。阅读页标题降低字号，使用正文衬线字体，摘要与标题左对齐。

新样式 `article-presentation.css` 位于已有样式之后，只调整文章。已有默认封面分配保留，图片静止时完整显示。桌面悬停增加图片轻微缩放、标题颜色与箭头位移；触屏不使用悬停状态。

`article-presentation.js` 观察首页与文章列表的卡片，进入视口时依次呈现封面和文字。只对内部元素使用 Web Animations，不与既有 MotionCore 的卡片/筛选变换竞争。不持续播放，不监听滚动事件；切换到减少动态效果、页面隐藏或离开时停止。筛选移除的元素取消动画并解除观察，浏览器往返缓存恢复后重新连接。

验证：`node scripts/check-article-presentation.cjs`，320、390、768、1080、1440、1920px 深浅色。测试捕获真实封面入场动画调用，核对桌面悬停、移动封面与文字位置、筛选、减少动态效果、阅读跳转、无横向溢出及浏览器错误。发布前使用 main 的页面与脚本副本再次检查。
