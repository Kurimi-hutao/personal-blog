# 手机国风刊物：素材生成说明

当前排版可直接使用现有素材。优先提供第 1 张日间主视觉，夜景和封面属于可选补充；无需生成整套网页 UI、图标或带字按钮。

## 1. 手机首页山水 · 优先

建议尺寸：1536×1920，竖版 4:5，PNG 或高质量 JPEG。不要压入手机外框，不要添加文字。画面左侧与上方必须留白，山体不跨过左侧文字区域。生成 2–3 个构图候选即可，不需要十几张同类图。

可直接发给 GPT：

> 为个人博客绘制一张克制的中国山水刊物插图，竖版 4:5，1536×1920。米白宣纸底，背景接近 #f5f2e9，但只保留非常细微的纤维质感。疏淡的灰墨远山、开阔水面、一处小山坡；主要景物集中在右侧 35% 与画面下方 30%，左上至少 55% 为平静、干净的米白留白，供网页另行叠加文字。用笔有干湿变化，山石结构自然，远近有呼吸感；少量低饱和朱红只用于一两处小叶或岸边细节。画面安静，墨色有节制，不铺满画纸。不出现人物、楼阁、仙鹤、巨型太阳、花瓣雨、发光、金色装饰、边框、印章、题字、书法、水印或界面元素。不要套用工笔游戏海报构图，不要绘制网页截图。保留完整画面，不要添加手机模型。

用途：替换手机首页现有山水图，代码负责文字和渐隐衔接。网页会转换为 WebP 并按小屏裁切，因此不要把关键物体放在边缘 8% 内。

## 2. 同构图夜间版 · 可选

在选定的日间图基础上编辑，保持山、水与留白的位置一致：

> 保持参考图的构图、景物形状和笔触，只改为沉静的夜间墨色。背景接近 #18211d，远山使用灰绿与灰白薄墨，左上留白仍清晰且平静；不用蓝紫渐变、霓虹光、星空、巨大月亮或强烈轮廓光。仍不出现文字、印章、边框或界面。输出同尺寸。

## 3. 去框文章封面 · 可选

仅在需要新封面时制作，建议 1536×864，横版 16:9。提供真实文章主题或角色参考图，保持主体可辨认；四周留出 8% 安全边距。不添加金边、卷轴边框、标题、徽章、伪书法、水印或复杂装饰。封面的色调与山水主视觉相近，但不要每篇都重复同一幅山景。作品页应优先使用作品自己的真实截图。

## 交付

可先提供日间图，确认构图后再做夜间版。直接提供原图文件；文字、导航、按钮、纸张噪点和分隔线由网页绘制，无需烘焙进图片。
