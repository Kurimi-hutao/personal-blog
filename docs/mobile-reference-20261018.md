# 手机端排版优化 · 2026-10-18

根据四张水墨博客参考图调整首页、文章列表、正文和作品页。仅在宽度不超过 900 CSS px 时加载 `mobile-reference.css`，保留桌面布局和现有内容、数据服务及交互。

- 首页强化书法栏目标题和朱红主按钮；文章采用 96px 缩略图与正文并排，摘要两行，整张卡片可进入文章。359px 以下切换为上图下文，长标题完整显示。
- 文章列表使用紧凑图文卡片；搜索框独立一行，分类与排序并排，清除筛选独立可点。栏目背景复用低对比山水素材。
- 正文基础字号调整为 17px，保持字号调节；增加段落与标题间距，以浅底引言和引用组织阅读节奏，减少纸纹干扰。
- 作品统一横幅封面和单列卡片，突出体验入口，源码及折叠创作说明继续可用；修复 841–900px 与旧桌面网格冲突。
- 复用已有 WebP 山水、角色头像和作品封面，没有引入新增图片下载。轮换服务工作线程缓存，沿用远端最新的脚本与样式网络优先策略。
