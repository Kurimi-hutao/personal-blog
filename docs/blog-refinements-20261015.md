# 博客功能与视觉优化（2026-10-15）

## 功能

- 首页主入口为阅读文章与浏览作品，绘卷和桃花互动保留为次级入口。
- 首页展示最近三篇未读完的文章，显示进度；收藏可从首页直接打开。阅读记录继续保存在当前浏览器。
- 搜索覆盖文章、视频及全部五个站内作品，支持类型筛选、结果数量及展开全部结果。作品包括征神图鉴、桌宠小屋等子站。
- 作品页、绘卷等页面在打开搜索时按需加载已有内容服务。接口不可用时，本地作品仍可检索，文章与视频提供缓存及重试提示。
- 首页和文章、视频列表读取失败时展示上次成功读取的公开内容，标明缓存日期并提供重试。缓存有效期为 14 天；没有发布内容与连接失败分别展示。
- 作品卡片补充可展开的创作目标、亮点与实现思路，内容依据现有作品实现编写。

## 视觉与加载

- 保留水墨场景与书法标题，正文和工具使用系统字体；单独生成仅含书法字体声明的 `fonts-headings.css`，原始字体资源保留。
- 头像生成 88px / 132px WebP，供 44px 标识在高密度屏幕使用。88px 文件为 3,586 字节，原始 PNG 为 1,677,609 字节。
- 字体样式从约 501KB 降至约 90KB。加载层等待字体最多 900ms，慢字体不再阻止阅读与导航。
- 手机首屏收紧留白，文章分区标题缩小；封面统一 16:9，摘要控制在三行内，辅助文字提高对比度。
- 正文页去除竖纹覆盖，降低纸纹强度；修正夜间品牌文字颜色。
- 更新相关资源版本及 Service Worker 缓存版本。

## 验证

本地预览命令：`python -m http.server 8015 --bind 127.0.0.1`。

- `node scripts/check-blog-refinements.cjs`：375、390、768、1440px 下检查首页、文章列表、视频列表、作品、文章正文和绘卷；验证续读、收藏入口、作品搜索、类型筛选、展开全部结果、缓存及重试恢复。
- 慢字体检查：字体尚在加载时，加载层已解除；接口失败时仍能找到桌宠小屋。另检查夜间作品页。
- `node scripts/check-loading.cjs`：正常动效和减少动效模式，字体失败、小屋日夜素材、Service Worker 按需缓存与离线导航。
- 新功能浏览器检查拦截写请求，内容使用合成测试记录，不修改线上数据。截图保存在本地 `outputs/blog-refinements/`。
- 本地测试首页资源传输约 3.9–4.2MB，书法字体请求为 13–15 个；包含合成封面等测试资源，不作为线上网速或 Lighthouse 分数。
