# 手机排版调整 · 2026-10-15

用户确认 A 的山水首页、文字目录与 C 的紧凑阅读排版。复用现有山水、头像与封面，无新增素材需求。

- 手机首页采用纸色、单列内容和文字链接，移除浮动工具条。
- 目录主入口按文章、作品、视频排列；次入口和搜索、主题、收藏、主动唤桃花分层排列。
- 阅读页固定返回、目录与更多操作，正文改为宋体、15px/2.05，保留字号设置、收藏、评论和续读。
- 手机点击粒子默认关闭；主动唤桃花支持减少动态效果。桌面保留原导航顺序与点击效果。
- 字体从现有 OFL 宋体素材生成常用字子集，373KB，font-display: swap；罕见字使用系统字体回退。生成脚本 scripts/build-mobile-serif.py 需要 fontTools。
- 删除旧 layout-polish.js，避免重复移动主题按钮。
