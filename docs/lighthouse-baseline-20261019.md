当前目录没有 Git 元数据，不能核验分支、提交差异或远端 Actions 执行状态。

已安装精确版本 @lhci/cli 0.15.1，并生成 package-lock.json。
CI 使用 Node 22、npm ci --ignore-scripts、desktop/mobile 矩阵。
预算使用三次中位数，目前设为警告，以保留未优化前的完整基线；
采集失败、运行错误、缺失指标、端类型错误或不足三次均不能生成有效摘要。

## 按影响程度排序的优化建议

以下建议依据本次报告提出，本次没有改动生产页面、样式或动画实现。

1. **优先缩短首屏 LCP 关键链。** 移动首页 LCP 元素是现有 hero-art，首个样本约 87% 耗时来自渲染延迟；
   首屏有 19 个样式表，报告估算阻塞资源可节省约 9.45 秒。
   先按页面整理首屏必要样式、减少阻塞样式传输，并核实生产 CDN 的 Brotli/gzip。
   保留水墨入场与 GSAP 时序，使首屏主体能尽早绘制。
   作品页的 LCP 是首张作品封面 zhengshen-atlas/hero.png，却设置了 loading=lazy；
   移动样本加载延迟约 12.95 秒，占 LCP 约 64%。优先让首屏封面提前可发现、使用合适尺寸的响应式资源，
   仅首屏封面采用积极加载，其余作品维持延迟加载。报告的图片尺寸审计估算作品页可节省约 1220KiB。
   上述节省值是审计估算，不能相加或当作优化后保证。

2. **稳定字体与异步区域的几何布局。** 文章/视频详情移动 CLS 中位数约 0.674，桌面作品页约 0.788；
   文章详情的偏移归因明确包含书法字体加载，列表与页脚也出现布局移动。
   建议匹配字体回退度量、稳定标题行高，为卡片、封面、播放器与加载状态保留一致尺寸，
   并让内容到达前后的骨架高度接近。保留书法字形、昼夜主题和原有进场效果。
   fonts-headings.css 的覆盖率提示不能直接视为所有 @font-face 可删除，应结合字体请求和全页交互复核。

3. **修复可定位的文字对比度。** 首页页脚备案链接被报告为约 3.4:1，未达该字号要求的 4.5:1。
   可小幅加深文字并同时验证明暗主题，保持水墨配色；其他页面按各自报告逐项复查。
   本次 SEO 均为 100，保留现有标题、描述与路由语义。

4. **随后降低冷启动 JS 传输量。** 首页 unused-javascript 提示约 363KiB 的首屏未使用字节，
   主要来自 Supabase、Lottie、GSAP 与 theme.js；但 TBT/JS 执行预算均已通过。
   建议按实际使用场景延后非首屏功能的加载，并保留依赖顺序与交互回归。
   首屏覆盖率不代表代码全站无用，不能据此直接删除动画库。
