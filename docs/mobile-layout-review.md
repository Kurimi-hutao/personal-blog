# 主站手机端排版复核（2026-09-29）

范围：卷首（含江湖去处、侠客志、留墨）、文章列表和详情、视频、作品列表、胡桃绘卷、桌宠小屋、404、站长登录页。未进入作品子站，也未检查登录后的管理界面。

## 修正

移动导航的关闭图标两条线中心相差约 6.5px：按钮使用 grid 自动分配行空间，而旋转位移仍按固定 8px 间距计算。改用共同的绝对定位中心，关闭时分别旋转 ±45°；保留 44×44px 点击区域。开启和关闭导航时同步更新按钮的无障碍名称。

更新主站 CSS、脚本引用版本及 Service Worker 缓存版本。

## 验证

运行 `node scripts/mobile-layout.cjs verified`。浏览器使用本地 Chrome 的移动视口：320×568、390×844、430×932、844×390，共 9 页 × 4 尺寸。

- 检查页面横向宽度、滚动后的内容边界、关闭图标中心、菜单末项滚动可达性和 Escape 关闭。
- 人工查看首页各区块、文章长标题与正文、视频、作品、绘卷、桌宠及登录页截图；检查菜单明暗主题。
- 文章长代码、宽表格、作品分类栏保留容器内横向滚动。
- 首页使用 content-visibility 优化，屏外节点的初始边界不作为排版缺陷；滚动进入视口后复核。
- 文章和视频内容由本地测试数据提供，不写入线上数据。

结果与截图位于 `screenshots/mobile-verified/`。这属于浏览器移动视口验证，未覆盖 iOS Safari / Android 真机、软键盘及后台登录后的状态。
