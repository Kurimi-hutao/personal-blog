# 手机素材接入与轻动效 · 2026-10-15

来源：用户提供的 mobile-publication-complete-assets，原始 PNG 保留在该目录。正式页面采用素材包现成的 WebP，没有重新生成或修改画面。

- 手机首页与目录背景采用日间 02 / 夜间 02，900px 以下切换；桌面延用既有画面。01 / 03 是备选原图，不同时展示。
- assets/mobile-publication 保存 02 日夜与两张概念封面的网页版本。
- 后台封面编辑器增加“从国风素材库选择”：物理科普、教育与阅读概念插画。点击只填入并预览图片地址，保留既有保存/草稿流程，不自动修改线上文章。
- 首页山水轻淡入 850ms（使用首页已有 GSAP）；目录逐项向上进入 320ms，间隔 28ms；搜索/阅读目录弹窗淡入 240ms。
- 按钮按压变淡、下移 1px，释放 200ms 小幅回弹；使用独立 scale 属性，避免旧 MotionCore 的 transform 规则遮盖反馈。
- 筛选选中下划线过渡 220ms，内容进入仅位移 12px；不增加点击粒子或后台持续动画。
- 滑动超过 10px、长按、失焦或 pointercancel 会取消按压；快速关闭目录清理入场动画。
- 减少动态效果、切换桌面、页面隐藏时清理受控动画。简单控件使用原生 Web Animations，无需在所有页面额外下载 GSAP。
