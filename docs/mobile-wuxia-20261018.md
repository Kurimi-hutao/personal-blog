# 手机端 AE 素材接入 · 2026-10-18

将已修正的 V3 原生 AE 渲染导出到 `assets/mobile-wuxia-v3/`。文章列表使用读书姿态，作品页使用持伞姿态，首页侠客志使用张望姿态，首页页尾使用休憩姿态。纸伞放在驿站标题旁，祈愿牌和朱印放在签到区域，水墨山河放在页尾。张望使用手臂随额头协调运动及完整铃铛轮廓的修正版；四种角色均为闭嘴表情。

角色主格式为 384 像素、60 fps、8 秒的透明 VP9 WebM。透明静态 WebP 封面用于初始展示；WebKit 或不支持 VP9 的浏览器按需使用 128 像素、24 fps 的透明动画 WebP。山河兼容版本为 320 像素。兼容图片比视频体积大，但仅在进入视口且允许播放时加载。具体体积见素材目录的 manifest.json。AE 工程、PNG 原始分层与高码率 MOV 保留在本地 outputs，不上传到站点。

`mobile-wuxia.js` 只在 900px 以下挂载，不预加载视频。进入视口才请求动态资源，同时最多播放两处。离开视口、页面隐藏、打开导航或对话框、pagehide 时暂停；减少动态效果及省流模式使用静态图片。页尾按钮可暂停画中动效，也会暂停桃枝与落花；偏好在当前浏览器保存。桌面断点清理节点和媒体连接。装饰不接收点击、不进入无障碍树。

四个页面接入独立样式与脚本，正文阅读页仅在页尾加入山河。service worker 更新版本，继续跳过视频及 Range 请求的缓存拦截。未添加新网络依赖。

验证：`node scripts/check-mobile-wuxia.cjs` 检查四页在 320/390/430/900px、明暗主题下的布局和实际播放，首屏延迟下载、减少动态效果、页面生命周期、桌面清理及恢复、手动暂停持久化和 WebKit 图片兼容路径。输出及截图保留在 outputs/mobile-wuxia-20261018；测试内容仅由本地浏览器夹具提供。
