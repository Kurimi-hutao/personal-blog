## 1. 统一视觉规范

- 风格：现代中式、水墨淡彩、宣纸与信笺，安静、清爽，装饰集中在边角。
- 日间颜色：纸色 #F4F3ED、墨色 #18201D、辅助文字 #56605A、朱砂 #9F3029。与博客现有变量保持一致。
- 夜间颜色：背景 #121715、文字 #ECECE3、辅助文字 #ADB7AF、朱砂 #D4665D。
- 内容优先：评论正文附近不放浓墨、花枝或纸张折痕；朱砂只用于发送、选中和身份强调。
- 标题建议沿用「卷后留评」。提示文案、昵称、时间、楼号、站长和置顶标记全部由网页显示。
- 使用现有字体。正文和表单优先保证可读性，书法感只用于少量标题。

## 2. 需要哪些素材

实际必需的是网页组件；图片都是增强氛围的可选装饰。建议先生成纸纹和空状态插画，其余按效果补充。

| 优先级 | 素材 / 建议文件名 | 数量与交付规格 | 用途 |
| --- | --- | --- | --- |
| 优先 | 宣纸微纹理 `comment-paper-tile.png` | 1 张，1024×1024，无缝平铺、不透明 | 编辑器和评论区域的轻纹理 |
| 优先 | 无评论插画 `comment-empty.png` | 1 张，1024×768，透明背景 | 无评论时的信笺、毛笔小插画 |
| 可选 | 标题边角插画 `comment-heading-sprig.png` | 1 张，1024×512，透明背景 | 标题右侧的一小枝梅花 |
| 可选 | 淡墨分隔 `comment-ink-divider.png` | 1 张，1536×128，透明背景 | 标题下或主楼之间的装饰分隔 |
| 可选 | 无字印章底纹 `comment-seal-base.png` | 1 张，512×512，透明背景 | 站长标记或发送成功提示的底纹 |
| 可选 | 默认头像 `comment-avatar-01~04.png` | 4 张，各512×512，透明背景 | 未来增加访客头像时使用；当前不是必需功能 |

现有项目已经有 `assets/visual-refresh/empty-comments.webp`，以及 `assets/minimal-ink/comment_input_minimal.png` 等素材。可先检查并复用；表单背景图只作为装饰，不能把图片里的输入框直接当成可交互控件。

以下内容直接用 CSS / SVG 制作，不需要逐个生成图片：输入框、发送按钮、回复区域、附件卡片、上传预览框、焦点边框、点赞状态、楼号、加载占位、错误提示。

功能图标建议同一套 SVG：图片、附件、发送、回复、点赞、关闭、展开、收起、重试。采用24×24坐标、1.5至2的统一描边、`currentColor`，方便缩放与切换主题。生成图片不等于可编辑 SVG。

## 3. 素材生成的统一前缀

每条独立素材提示词前都加上这一段；优先把已满意的第一张素材作为后续生成的风格参考。

```text
为现代中式水墨个人博客制作独立网页装饰素材。统一为克制的东方水墨淡彩插画，细腻宣纸感，干净轮廓，墨色 #18201D，暖灰与米白 #F4F3ED，极少量朱砂红 #9F3029。平视、近似二维表现，细节在缩小后仍清晰。构图简洁，适合精致的阅读网站。仅生成本次指定的单个素材，不生成整套拼图，不带网页界面，不带文字、字母、数字、水印、品牌标识。避免浓重仿古黄、赛博霓虹、厚重三维效果、大面积泼墨、繁复边框和杂乱背景。
```

透明素材须在工具中同时开启透明背景选项；白色背景或棋盘格图案不等于透明通道。

### A. 宣纸微纹理

```text
生成一张可在上下左右连续无缝平铺的浅米白宣纸微纹理，正方形，建议1024×1024。底色接近 #F4F3ED，仅有非常细微的暖灰纤维和柔和纸浆颗粒，明暗差很低，整体均匀，文字叠加后容易阅读。四边自然衔接，没有明显主图案，没有中心聚光，没有阴影、折痕、破损、泛黄、污渍或画框。不透明背景，铺满整个画布。
```

交付检查：将图片重复平铺为3×3，检查接缝；无缝效果需要实际验证，不能只依赖提示词。

### B. 无评论插画

```text
生成一张用于博客评论区空状态的小插画，横向4:3构图，建议1024×768，真实透明背景。主体是一张尚未书写的暖白信笺，旁边放着一支细毛笔和小巧墨碟，一片淡朱砂色花瓣轻轻落在纸边。信笺仅略微错落，毛笔朝向画面内部。主体完整、居中，四周留出约15%的透明安全边距，装饰精简，没有桌面、场景背景或投影色块。纸上没有任何文字或符号。缩小到宽160像素时仍能辨认信笺和毛笔，气质温柔、安静、有等待第一句话的感觉。
```

搭配网页文字：「此卷尚待落墨」「还没有评论，来写下第一句吧。」

### C. 标题边角梅枝

```text
生成一张横向2:1构图的极简水墨梅枝装饰，建议1024×512，真实透明背景。细而自然的灰墨枝条从画面右边向左下方轻轻延伸，只有三至五朵很小的淡朱砂梅花与少量花苞。画面左侧至少60%保持完全透明，枝条集中在右下区域；完整保留末梢，不裁切花朵。线条轻盈，整体墨量极少，适合放在网页评论区标题旁，不抢夺标题和正文注意力。不含文字、印章或背景纸张。
```

### D. 淡墨分隔线

```text
生成一条用于网页的极细横向淡墨笔触，画布比例12:1，建议1536×128，真实透明背景。一笔从左向右轻轻掠过，主体位于画布纵向中线，两端自然收笔，线条大部分纤细、低对比，仅有少量自然飞白。上下留出充足透明空间，不出现大片墨团、滴墨、山水、花枝或文字。整体接近暖灰，缩小到宽600像素、高20像素时仍像安静的细线。
```

### E. 无字印章底纹

```text
生成一个小巧的朱砂方章底纹，正方形画布，建议512×512，真实透明背景。主体居中，占画布约70%，采用偏暗朱砂红 #9F3029，边缘有少量自然印泥不均匀和细微缺口。内部是较均匀的印泥色面，可供网页后续叠加两个白色汉字；内部纹理不能太花。没有任何文字、篆字、符号或外部阴影。小尺寸下轮廓清楚，不要做成巨大破损的古印。
```

正式的小尺寸「站长」和「置顶」标记优先使用 CSS 边框与真实文字，底纹只是可选修饰，不能影响识别。

## 6. 素材交付检查

- 每个素材独立一张，不交付九宫格或带设备外框的展示图。
- 透明图片保留真实 Alpha 通道，边缘无白边；插画无乱码文字或假棋盘格。
- 保留 PNG 原图；网页版本可以导出透明 WebP。避免把有损小图反复放大。
- 检查实际显示尺寸：空状态约160至220像素宽；标题装饰约96至140像素宽；头像32至40像素；印章约24至32像素。
- 深色模式对素材逐张检查；若浅色信笺过亮，隐藏该装饰或准备深色变体，不对全部插画统一反色。
- 图片压缩后检查清晰度；装饰按使用位置加载，不影响评论正文与表单出现。
