# 手机桃枝与落花 · 2026-10-18

首页、文章列表、作品页和阅读页增加透明桃枝，复用此前的手机端排版。新增 `assets/mobile-botanicals/peach-branch.svg` 是本地绘制的矢量素材，包含枝干、花朵与花苞，可适配不同分辨率。

`mobile-botanicals.js` 仅在 900px 以下挂载装饰。使用浏览器原生 Web Animations API，与现有 GSAP 首页及无 GSAP 的栏目页共存：枝干以右上根部为轴，在 9.2 秒周期内小幅摆动；四片花瓣错开落下，带旋转、侧向漂移与翻面。不使用持续计时器，也不持续创建 DOM 节点。

装饰忽略指针、不可聚焦并从无障碍树中隐藏。正文页装饰裁切在标题上方；页头离开视口、页面隐藏、打开导航或对话框、pagehide 时暂停，恢复可见时继续。开启减少动态效果时保留静态桃枝并隐藏落花；切换到桌面宽度时取消动画、移除节点。

验证：`node scripts/check-mobile-botanicals.cjs` 检查 320、390、430、900px 明暗主题、四个页面，确认动画时间推进、枝干变换、花瓣数量、装饰不拦点击、无溢出、导航暂停、离屏暂停、减少动态效果和跨断点清理。`node scripts/check-mobile-reference.cjs` 回归此前排版与交互。截图和动画预览存放于 `outputs/mobile-botanicals-20261018/`，测试数据仅用于浏览器拦截，不写入生产。
