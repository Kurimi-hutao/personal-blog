# 手机排版与播放键更新

- 手机目录关闭后，导航整体设为 `inert`，并隐藏其子控件；打开时恢复，跨过 1080px 断点时同步状态。原问题由工具按钮单独设置 `visibility: visible` 和 `pointer-events: auto` 引起，关闭后的原坐标仍可切换主题。
- 首页与视频列表的播放标记改为圆形磨砂底、细边框与三角图标，适配深浅色，覆盖手机和桌面。
- 900px 以内，文章卡片使用约 2.85:1 的通栏横幅封面，分类与日期分居两侧，标题与摘要最多两行。首页和文章列表共用比例。
- 900px 以内，驿站使用双列六个常用入口、单列分类卡片、圆形箭头，复用已有水墨素材，保留分类展开与收起。

验证：`node scripts/check-mobile-redesign.cjs` 检查 320、390、430、900、1080、1440px，均覆盖深浅色。包含目录关闭坐标命中、键盘焦点、快速开关、响应式切换、可见主题按钮、分类展开收起、横向溢出和双端播放键。发布前额外以 main 的页面和脚本进行隔离验证，桌面文章及驿站的尺寸、字号、背景保持不变。`node scripts/check-mobile-reference.cjs` 的七个宽度深浅色检查与现有 14 项回归检查通过。

主站仅提交本次修改，保留 main 的独立样式加载方式；本地既有的样式打包与性能优化分支不包含在本次提交中。样式与主题脚本带新版本号，Service Worker 缓存版本同步更新。
