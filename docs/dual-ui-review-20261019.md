# 博客双端交互与视觉检查 · 2026-10-19

已在本地完成桌面、手机及平板断点检查，并修复四类实际复现的问题。整体保留现有水墨、朱砂、宣纸风格；主按钮、文字入口、播放按钮与导航的层次协调，无需整体重做。

- 首页、文章列表、文章详情、视频列表、视频详情、作品、胡桃绘卷、小屋、404 和后台登录，共 10 个页面/状态，在 390、768、1080、1440、1920px 下分别保存明暗主题截图，共 50 个页面与尺寸组合。

- 普通动画、减少动态效果、运行时切换偏好、菜单快速开关、连续筛选、花瓣清理、动图播放/暂停/断点切换、WebKit UA 图片回退。

所有浏览器检查使用隔离存储、合成文章/评论和本地资源拦截，没有向真实内容服务写入数据。

## 已修复

| 问题 | 复现与影响 | 修复 |
| --- | --- | --- |
| 搜索结果被弹窗裁切 | 320×430 下弹窗内部滚动高度 466px，实际只有 402px；结果区域伸出弹窗。844×390 横屏和 1440×600 桌面短窗口同样出现 | 约束弹窗与内层高度，使用可收缩的 flex 结果区域；短屏缩减留白、快捷入口横向滚动，保留独立的结果滚动 |
| 筛选入场动画持续覆盖交互样式 | 入场完成后仍有 5 个 `fill: both` 动画驻留，CSS 悬停和按压无法接管同名属性 | 动画完成后释放关键帧，连续筛选时同时取消旧入场和退场动画；最终动画完成后释放占位高度 |
| 减少动态效果下键盘仍触发按压动画 | 键盘处理遗漏偏好判断；空格按下后仍添加按压状态 | 键盘与指针统一尊重偏好，偏好切换时清除已有按压/回弹状态 |
| 筛选菜单快速关闭后焦点被夺走 | 打开后立即关闭，40ms 的延迟聚焦仍把焦点拉回正在退场的选项 | 关闭/取消动画时清除聚焦计时器，并在聚焦前再次核对打开状态 |

搜索框外观也做了局部调整：焦点反馈改为整条输入区域的朱砂底线，避免框内再套一个醒目的红色矩形；键盘焦点提示保留。
