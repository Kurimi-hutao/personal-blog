# 首页、控件与 SEO 回归修复

已复现：旧 SSG 正则在首页卡片内第一个 `</div>` 截断替换，导致占位卡片成为容器外的兄弟节点；桌面回顶部/桃花被旧边缘隐藏规则移出屏幕。平板导航 JS 的 1080px 断点与实际加载样式的 900px 断点不一致。

修复采用 parse5 的真实元素边界替换；覆盖文章、视频、课程和详情插槽，缺失/重复 ID 立即中止构建。静态卡片沿用现有结构与封面，后台刷新失败保留正文。桌面控件统一为独立 48px 点击区，手机沿用导航工具与页尾返回入口；统一断点为 900px。搜索在接口故障时仍使用公开构建快照。“接着翻阅”增加说明和阅读入口。去掉视频详情中代理/完播实现说明，不修改作者正文。

性能：发布时对 HTML/CSS/JS 等文本进行确定性 gzip，按实际上传字节计算哈希并验证；保留原 URL 和 Content-Type，添加正确 Content-Encoding。移动字体改为 optional，减少慢网字体替换导致的重排。课程第 18 课本地移动实验：Lighthouse SEO 100、性能 68，LCP 6.4s、CLS 0、传输量 1090 KiB。与此前 60 分/11.3s 相比有改善，但仍不达理想值；这是本地模拟，不是线上真实用户指标。

验证：21 项 Node 测试通过（含先失败后通过的占位残留回归）；1440px、1024px、390px 的控件中心命中、主题切换、桃花入口、返回顶部、离线搜索与代码块横向滚动检查通过。生产接口写入被测试拦截。测试脚本：scripts/check-release-browser.cjs，可设置 SITE_ORIGIN 复验线上。

IndexNow 新增独立随机所有权验证键，放在 `.github/indexnow-key.txt`，构建生成协议要求公开的同名验证文件。它不是账户密码；百度 token 仍只从 GitHub Secret 读取。部署后逐页核对内容和 canonical，再由 CI 提交，HTTP 接收不等于收录。若首次返回 202，表示所有权验证尚未完成，需要随后重试；不要把它写成已收录。

未冒充解决的项目：百度缺少 BAIDU_PUSH_TOKEN/站点认证，无法代为取得；软 404 必须由 CloudBase 域名网关正确返回状态码。SDK 5.9.0 明确禁止修改共享存储桶的静态网站配置，部署增加真实缺页状态检查与 Actions 警告，不绕过共享桶保护。上一轮 SEO 已成功发布（CloudBase #53），本次继续走同一部署流程。

本地证据：outputs/repair/local-checks.json、lighthouse-mobile.json。后续线上复测结果以 live-checks.json 和 GitHub Actions 日志为准。
