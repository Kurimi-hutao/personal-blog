# 手机控件系统 · 2026-10-15

针对用户反馈的按钮过于简单，重新设计手机端操作控件。保留已确认的山水首页与宋体阅读排版，使用 mobile-controls.css 集中管理控件，HTML 媒体条件限制在 1080px 以下，桌面保持原行为。

## 视觉与状态

- 主操作：朱印底色、内描边、轻微底边阴影；按压下移 1–2px，释放复位。
- 工具操作：纸色底、墨色边框、统一 24px 线稿图标，包含搜索、主题、收藏、桃花、目录、分享、图片、附件与发送。
- 导航：编号印框、当前栏目实色状态、成组的次入口与图标工具栏。
- 阅读：返回和目录可辨认的按钮、成组字号调整与收藏状态、点赞和分享工具。
- 筛选：成组分类、选中状态、输入与选择框统一；评论输入与附件工具采用同一套边框与状态。
- 所有新增图标为原创代码 SVG，保存在 assets/mobile-ui。无需额外素材或第三方图标库。
- 支持浅色/深色主题、44px 以上触摸目标、键盘焦点与减少动态效果。按钮沿用原生链接/按钮，CSS 装饰不改变辅助技术标签。
