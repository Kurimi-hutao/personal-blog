# 水墨博客专项修复验收（2026-11-14）

本次只修改本地源码，没有部署、推送、修改数据库或生产内容。当前目录没有 `.git`，无法判断它相对远端的未提交修改；修改前的根目录源码保存在 `outputs/ux-repair/before/`，逐行差异见 `changes.patch`。没有重置用户源码、缓存或已有 `_deploy`。

## 已解决及根因

- **数学公式时序**：旧代码依赖一次性的 window.load；事件已经触发后，迟到的排版依赖无法再执行。现使用有上限的依赖等待，正文排版前不可见，成功后建立目录；5 秒不可用时恢复原文、显示说明和可重新加载依赖的排版重试。重复调用跳过已完成正文。
- **内容加载**：文章、视频列表以前等请求失败才读缓存。现先显示带日期和更新状态的缓存，再请求最新内容；失败保留缓存或内存内容并提供重试，空缓存失败不会显示成空列表。防止同一列表重入，并合并并发相同公共查询。详情请求增加 10 秒中止；旧 schema 无视频字段时返回错误而不是虚假的空列表。首页已有快照、课程缓存、骨架屏继续复用。
- **卡片与图片**：文章/视频/作品保留稳定卡片节点，文章仅更新搜索高亮文案；首批列表图片优先加载，补尺寸，视频图片加载成功后淡入，标题占位改为纸色。修正旧退出动画残留透明度导致复用卡片不可见的问题。视频与作品增加 URL/前进后退同步，文章筛选保留历史记录。
- **桌宠**：原运行时脚本改为 defer，按原依赖顺序执行、并行获取。基于模型目录、模型、纹理的真实事件提供阶段状态，25 秒未完成进入可重试错误，保留上一角色。故障注入发现 vendor 在 JSON 失败时销毁未初始化模型会抛异常，已保护清理路径；真实失败后的重试已成功加载完整模型。
- **桃花**：修复无 event 的直接调用异常；普通手机 12 片、桌面 20 片起，低性能设备 6 片起，分别限制总量，尺寸 24–42px，飘落约 3.1 秒以上。保留原花瓣素材、点击穿透、动态偏好反馈和结束移除。
- **弹窗与主题**：搜索 CSS 退出 240ms 而 JS 原来 170ms 就关闭，现等退出完成；补初始进入样式，防止关闭后延迟抢焦点。画廊增加图片加载淡入、180ms 退出、ESC 与遮罩关闭统一处理和滚动锁。桌面主题按钮不再被自动隐藏规则平移到视口外；显式主题切换时增加有限范围背景/文字/边框过渡。
- **视觉精修**：保留日夜山水素材和现有布局；江湖驿站品牌图标容器改纸色边缘，画廊细滚动条、阅读进度朱砂标记、视频纸色占位。文章明确标记 role=cover 的图片在标题后等比显示，不将自动生成列表封面强塞正文。

## 实测结果

使用安装的 Chrome + Playwright、真实本地 JS/CSS/图片/字体/KaTeX/Live2D，公共内容请求由浏览器隔离 fixture 提供；外部请求默认阻断，不写生产数据。

- 390×844、768×1024、1440×900 × 正常/减少动态效果 × 7 页面，共 **42 个组合通过**。页面：首页（含 #links 江湖驿站）、文章列表、文章详情、视频、作品、胡桃绘卷、桌宠。
- 各组合日夜样式下无页面横向溢出；正常路径 pageerror 记录为空。此项并非所有文字的对比度审计。
- 手机与桌面桃花触发后 200ms 内 DOM 可见，连续调用粒子数量有上限；减少动态效果下显示静态反馈。视觉截图为本地测试内容。
- 作品/视频筛选往返保留节点身份，退出/进入完成后 opacity=1；搜索 ESC 关闭解除锁定；画廊 ESC 关闭解除锁定。桌面按钮边界在视口内。
- 独立新浏览器 context 延迟 KaTeX 脚本：正文在原始公式阶段隐藏，依赖就绪后正常显示。window.load 后再提供依赖也能渲染。
- 行内、积分块级、长公式：3 个 KaTeX 节点、0 个错误，重复调用仍为 3 个，390px 无页面横向溢出。截图 math-390.png。
- 缓存命中后模拟请求失败：文章与视频都保留原卡片、显示回退说明，点击重试可恢复。
- 空缓存失败显示错误；恢复后 7 张测试视频封面均 naturalWidth > 0。此数字是受控样本，**不是线上 7 条视频验收结论**。
- 模拟文章请求持续不返回：10 秒中止后出现可重试错误。
- 阻断公式自动渲染资源：5 秒后原文可读；恢复资源后点击排版重试成功。
- 阻断真实 Live2D 模型 JSON：出现原重试按钮；恢复后点击重试，真实模型达到 ready。
- `npm run test:regression`：22/22。
- `npm run test:perf`：2/2。这是性能测试配置与 fixture 检查，**不是 Lighthouse 性能分数**。
- 根目录 JS 与新增测试脚本语法检查通过；`npm run assets:styles` 成功。
- 原 `npm run build` 为保护已有 `_deploy` 按设计拒绝覆盖。使用项目现成 `LHCI_BUILD=1` 独立输出后构建成功：2068 文件，323.4 MiB。最终输出 `.lighthouseci-site/`；没有发布。
